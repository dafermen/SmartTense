# Contributing

Read `AGENTS.md`, `CURRENT_STATUS.md`, and `docs/INDEX.md`. Open an issue for consequential schema, privacy, product, or architecture changes, and create an ADR when needed.

Keep changes focused, mobile-first, bilingual, content-driven, tested, and documented. Complete the 13-category review and `npm run release:check` before a pull request.

## Licensing

The project owner has not selected the repository license. Do not accept external contributions until license and contribution terms are approved.
